Architecture

6-Stage Analysis Pipeline

From raw web pages to clustered insights — a complete NLP workflow

1

🌐 Web Crawling

Crawls articles from BBC Sport, Sky Sports, and premierleague.com using requests + BeautifulSoup. Includes retry logic, rate limiting, and multi-strategy HTML extraction.

2

🔧 Text Preprocessing

8-step NLTK pipeline: HTML removal → URL stripping → lowercasing → punctuation removal → tokenization → stopword removal (English + custom EPL words) → lemmatization → short word filtering.

3

📊 TF-IDF Vectorization

Transforms cleaned text into numerical feature vectors using Term Frequency–Inverse Document Frequency. Produced a matrix of 60 documents × 794 features with sublinear TF normalization.

4

😊 Sentiment Analysis

VADER (Valence Aware Dictionary and sEntiment Reasoner) scores each article on a compound scale from -1 to +1. Classified 78% as positive, 20% negative, and 2% neutral.

5

🔬 K-Means Clustering

Optimal K selected by Silhouette Score; the Elbow Curve is provided as a diagnostic. K-Means partitioned 60 articles into 10 thematic clusters. PCA reduced 794 dimensions to 2D for visualization.

6

📈 Visualization & Export

Generated 9 publication-quality charts (word clouds, scatter plots, elbow curve, sentiment distributions) and exported all results to CSV.

Theory

Methodology

The algorithms and techniques powering this analysis

📊

TF-IDF Vectorization

Measures word importance relative to the corpus. High scores = distinctive terms. Low scores = common terms.

TF-IDF(t,d,D) = TF(t,d) × log(N / df(t))
🔬

K-Means Clustering

Partitions documents into K groups by minimizing within-cluster distance to centroids.

min Σᵢ Σₓ∈Cᵢ ‖x − μᵢ‖²
😊

VADER Sentiment

Lexicon-based analyzer producing compound scores from -1 (negative) to +1 (positive).

compound ≥ 0.05 → Positive
compound ≤ -0.05 → Negative
📉

Elbow Method

Plots inertia vs. K as a diagnostic; the pipeline selects K using the Silhouette Score.

K* = argmin rate_change(Inertia(K))
📐

PCA Reduction

Projects 794-dimensional TF-IDF vectors into 2D space while preserving maximum variance.

X₂D = PCA(X_tfidf, n_components=2)
🌐

Web Crawling

HTTP requests with BeautifulSoup HTML parsing. Multi-strategy extraction with retry logic and rate limiting.

requests.get() → BeautifulSoup(html)
